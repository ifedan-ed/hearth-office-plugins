# Speech input

Typing by speaking in Hearth Office's editors: a Speech input button on
the Home tab starts and stops it, and a small panel shows the words still
being heard. Hearth's own Dictate does the work on Hearth's page (the
microphone, the pieces of speech, the speech model through the model
proxy, the spoken commands such as "full stop" and "new paragraph"); the
add-in types each finished piece at the cursor, joined to the text before
it with a space and a capital where a sentence starts.
